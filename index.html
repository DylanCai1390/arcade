Under the hood

How this site is built

  • HTML and CSS only

    No JavaScript and no frameworks. The crossword’s typing, mistake checking, and solution reveal all come from plain HTML elements and modern CSS selectors.

  • Keyboard friendly

    Every link, square, and control can be reached with the Tab key, and the focused element always shows a bright yellow marker.

  • Phone first

    Layouts start at 320 pixels wide and grow from there. On small screens the navigation moves to a thumb-friendly bar at the bottom.
